# Mayday for Windows 2.1.4

## What's New

- Bundled a refreshed Windows runtime with connection lifecycle improvements.

## Fixes

- Improved reconnect reliability after turning the protected connection off and on repeatedly.
- Fixed a case where the app could show the connection as active even though the protected connection had not fully recovered after reconnecting.

## Compatibility

- Supports Windows 10 and Windows 11 on 64-bit PCs.
- Requires a current Mayday access key for the current runtime configuration contract.

# Mayday для Windows 2.1.4

## Что нового

- В сборку включен обновленный Windows runtime с улучшениями жизненного цикла подключения.

## Исправления

- Повышена надежность повторного подключения после последовательности «включить, выключить, включить».
- Исправлен сценарий, когда приложение могло показывать подключение как активное, хотя защищенное подключение после повторного запуска фактически не восстановилось.

## Совместимость

- Поддерживаются Windows 10 и Windows 11 на 64-битных ПК.
- Для текущего контракта конфигурации runtime нужен актуальный ключ доступа Mayday.
